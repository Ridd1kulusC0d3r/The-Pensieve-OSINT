# Contributing

The goal is a useful analyst arsenal, not a landfill of links.

## Add a resource

A contribution should include:

- name;
- canonical URL;
- category;
- accepted input(s);
- primary purpose;
- access model: free / freemium / paid / open source;
- account/API requirement if relevant;
- region when relevant;
- limitations or caveats.

## Curation rules

Prefer:

1. original/official source;
2. maintained tools;
3. clear investigative value;
4. reproducible results;
5. resources with documented limitations.

Avoid:

- duplicate mirrors;
- SEO listicles;
- unmaintained clones when an active upstream exists;
- services with unclear provenance;
- tools whose main value is bypassing access controls;
- resources that encourage unnecessary exposure of personal data.

## Pull request format

Explain:

- what is being added or changed;
- why an analyst would use it;
- where it fits in the workflow;
- how you verified the link/project exists.

If replacing a resource, explain why the replacement is better or more current.
