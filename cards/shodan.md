# Source Card: Shodan

- **Type:** internet intelligence index
- **Inputs:** IP, domain, service
- **Outputs:** indexed host/service metadata
- **URL:** https://www.shodan.io/
- **Access:** freemium/commercial
- **Stage:** collect / infrastructure context

## Useful for

Understanding services previously observed by a third-party internet scanner.

## Limitations

Coverage and freshness vary. Indexed data does not prove a service is currently exposed, nor does shared infrastructure prove ownership.

## Verify with

RDAP, ASN/BGP context, Censys/Netlas and direct validation only when explicitly authorized.
