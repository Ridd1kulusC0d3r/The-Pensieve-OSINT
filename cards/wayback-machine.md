# Source Card: Internet Archive Wayback Machine

- **Type:** web archive
- **Input:** URL, domain
- **Output:** archived snapshot
- **URL:** https://web.archive.org/
- **Stage:** verify / historical context
- **Region:** global

## Useful for

Historical page content, removed/changed pages and temporal context.

## Limitations

Archive coverage is incomplete. Capture time is not automatically the original publication time. A missing snapshot is not evidence that a page never existed.

## Verify with

Other archives, live primary sources and dated first-party records where available.
