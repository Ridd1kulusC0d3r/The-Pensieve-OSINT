# Pensieve Knowledge Graph

The graph is the relational memory layer.

## Node types

- `Tool`
- `Source`
- `Input`
- `Output`
- `Playbook`
- `Project`
- `INT`
- `Region`
- `Pattern`

## Core edges

```text
Tool      --accepts------> Input
Tool      --produces-----> Output
Tool      --used_in------> Playbook
Source    --covers-------> Region
Project   --specializes--> Playbook/Input
Playbook  --uses---------> Tool
Pattern   --warns_about--> Inference
INT       --contains-----> Technique/Playbook
```

## Example questions the graph should answer

- Which tools accept `domain` and produce infrastructure context?
- Which playbooks depend on archive sources?
- Which resources cover Brazil?
- Which outputs require additional corroboration?
- Which specialist repository should an analyst open next?
- Which tools are alternatives rather than independent corroborating sources?

## Provenance principle

A graph edge is an analytical relationship. It is **not automatically evidence**.

Whenever a graph edge comes from a real investigation, the case system should preserve its evidence IDs separately from this public knowledge graph.

The Pages graph is generated by `scripts/build_catalog.py`.
