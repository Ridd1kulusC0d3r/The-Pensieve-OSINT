# Intelligence Taxonomy

The Pensieve uses a broad intelligence taxonomy while keeping a strict distinction between **open-source practice** and disciplines that are included only for conceptual context.

| INT | Name | Open-source applicability | Pensieve use |
|---|---|---:|---|
| OSINT | Open Source Intelligence | Full | Core discipline |
| SOCMINT | Social Media Intelligence | Full for public data | Public social-platform research |
| GEOINT | Geospatial Intelligence | Partial | Maps, satellite, terrain and geolocation |
| IMINT | Imagery Intelligence | Partial | Public imagery verification |
| CYBINT | Cyber Intelligence | Partial | Public/authorized cyber infrastructure context |
| CTI | Cyber Threat Intelligence | Partial | Defensive threat intelligence |
| FININT | Financial Intelligence | Partial | Public corporate/financial records |
| TECHINT | Technical Intelligence | Partial | Technical analysis from lawful public evidence |
| DOMEX | Document & Media Exploitation | Partial | Lawfully obtained public documents/media |
| HUMINT | Human Intelligence | Context only | Taxonomy/reference only |
| SIGINT | Signals Intelligence | Context only | Taxonomy/reference only |
| MASINT | Measurement & Signature Intelligence | Context only | Taxonomy/reference only |
| MEDINT | Medical Intelligence | Context only | Taxonomy/reference only |

The machine-readable version lives in [../knowledge/int-taxonomy.json](../knowledge/int-taxonomy.json).

## Why include context-only disciplines?

Because an analyst should understand how intelligence disciplines relate without pretending that every discipline is an OSINT technique. The Pensieve does **not** provide operational collection guidance for restricted/non-open disciplines.
