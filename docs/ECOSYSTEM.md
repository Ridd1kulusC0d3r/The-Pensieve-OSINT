# Ridd1kulusC0d3r OSINT Ecosystem

The Pensieve is the **navigation layer**. These repositories cover specialized functions.

## Flagship projects

| Project | Role |
|---|---|
| [Mineiro Username Intelligence](https://github.com/Ridd1kulusC0d3r/Mineiro-OSINT-Extractor) | Username/public-presence investigation, evidence engine, correlation graph and auditable reporting |
| [T.O.C.A.I.A](https://github.com/Ridd1kulusC0d3r/tocaia-osint) | Behavioral OSINT, collection coverage and analysis of meaningful absence |
| [OSINT Checklist](https://github.com/Ridd1kulusC0d3r/osintchecklist) | Investigation method, quick logbook, evidence/entities/timeline/findings and decision flow |
| [F.I.O. Lab](https://github.com/Ridd1kulusC0d3r/FIO) | Brazilian public-data and identifier laboratory |
| [Tropeiro Intel](https://github.com/Ridd1kulusC0d3r/tropeiro-intel) | Defensive OSINT and threat-intelligence workflow for phishing/fraud campaigns |

## Suggested navigation

```text
Need methodology?      → OSINT / osintchecklist
Need username hunting? → Mineiro
Need behavioral OSINT? → TOCAIA
Need Brazil records?   → FIO
Need phishing/CTI?     → Tropeiro Intel
Need talks/training?   → OSINT Uai / T4lks
Need broad discovery?  → The Pensieve
```

The goal is **complementarity**, not cloning the same README into twelve repositories and hoping nobody notices.
