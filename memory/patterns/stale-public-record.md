# Pattern: Stale public record

## Observation

An official or reputable record contains an address, officer, status or identifier that conflicts with newer evidence.

## Possible explanations

- reporting lag;
- administrative delay;
- historical record;
- delayed deregistration;
- source refresh cadence.

## Do not infer

Do not treat one timestamped public record as permanently current.

## Useful checks

Record the source reference date, seek newer filings and compare independent primary records.

## Confidence impact

Freshness uncertainty lowers confidence in present-tense conclusions, not necessarily in historical conclusions.
