# Pattern: Username collision

## Observation

The same or very similar username exists on multiple platforms.

## Possible explanations

- same person;
- common word/alias used independently;
- impersonation;
- fan/community account;
- recycled handle;
- automated/bot account.

## Do not infer

A matching handle does not prove a shared operator or identity.

## Useful checks

Compare public profile-native metadata, creation/timeline clues, linked sites, recurring media and explicit cross-links. Record contradictions.

## Confidence impact

Username-only matches should remain candidate-level findings.
