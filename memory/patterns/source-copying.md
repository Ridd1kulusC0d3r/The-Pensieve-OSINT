# Pattern: Source copying and false corroboration

## Observation

Several websites repeat the same claim.

## Possible explanations

- genuinely independent reporting;
- syndication;
- copied database;
- one upstream article repeated elsewhere;
- automated aggregation.

## Do not infer

Five URLs do not equal five independent sources.

## Useful checks

Trace publication times, wording, citations, dataset lineage and original documents.

## Confidence impact

Corroboration increases confidence only when evidence is meaningfully independent.
