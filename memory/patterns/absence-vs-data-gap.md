# Pattern: Absence vs data gap

## Observation

An expected public artifact or event is not observed.

## Possible explanations

- the event did not occur;
- collection coverage was incomplete;
- the source changed or blocked access;
- the event was removed or never indexed;
- the analyst used the wrong time window or identifier.

## Do not infer

“No result” is not automatically evidence of absence.

## Useful checks

Measure source coverage, test alternative sources, inspect archives and document collection failures.

## Confidence impact

Only treat absence as analytically meaningful when collection coverage makes the expected observation reasonably detectable.
