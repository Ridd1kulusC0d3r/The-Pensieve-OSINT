# Pattern: Shared corporate address

## Observation

Several organizations appear at the same public registry address.

## Possible explanations

- accounting office;
- registered agent;
- virtual office;
- coworking location;
- parent/subsidiary relationship;
- genuinely shared operational premises.

## Do not infer

Do not infer common ownership, coordinated activity or operational relationship from the address alone.

## Useful checks

- compare officers/partners;
- inspect historical address dates;
- check whether the address belongs to a professional intermediary;
- compare public contact details and official filings;
- record whether the relationship persists over time.

## Confidence impact

Treat address-only correlation as weak until independent evidence supports the relationship.
